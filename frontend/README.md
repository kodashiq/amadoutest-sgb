# Portfolio Amadou Fofana

Portfolio professionnel construit avec React 19 et Vite. Il présente le parcours, les projets et les compétences d'Amadou Fofana dans les domaines du bâtiment intelligent, de l'énergie et de la gestion de projet.

## Fonctionnalités

- Présentation professionnelle et téléchargement du CV
- Trois projets issus d'expériences réelles
- Recherche par titre, résumé, technologie ou domaine
- Compétences organisées par groupes avec niveaux
- Thème clair/sombre mémorisé dans le navigateur
- Mise en page responsive

## Technologies

- React 19
- Vite
- JavaScript ES modules
- CSS responsive
- JSON comme source de contenu

## Lancer le projet

```bash
cd frontend
npm install
npm run dev
```

La page est disponible sur `http://localhost:5173`.

## Vérifier le projet

```bash
npm run lint
npm run build
npm run preview
```

## Structure

- `src/App.jsx` : assemblage des sections
- `src/components/` : composants React réutilisables
- `src/data/portfolio.json` : contenu du portfolio
- `src/hooks/useTheme.js` : gestion du thème clair/sombre
- `public/cv-amadou-fofana.pdf` : CV téléchargeable
